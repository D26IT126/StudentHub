# Student Event Management System

## Overview

The Student Event Management System is a web-based application developed to simplify the organization and management of college events. It provides a centralized platform where students can access event-related information and administrators can efficiently manage events and student records.

The system offers separate interfaces for students and administrators based on their roles. Students can register, log in, view their dashboard, access their profile, and submit feedback. Administrators can log in to a dedicated dashboard to manage student information and oversee event management activities.

The primary objective of this project is to reduce manual work, improve the efficiency of event management, and provide an organized, user-friendly platform for both students and administrators.
